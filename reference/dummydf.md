# dummydf: an accessibletablesR demo data.frame object

A dataset for the purpose of demonstrating how the accessibletablesR
package can be used.

## Usage

``` r
dummydf
```

## Format

A data frame with 32 rows and 15 columns.

## Source

mtcars
https://www.rdocumentation.org/packages/datasets/versions/3.6.2/topics/mtcars

## Details

- Car:

  Model of car (character)

- Miles per US gallon:

  Fuel consumption (numeric)

- Number of cylinders:

  Number of cylinders in car engine (numeric)

- Displacement (cubic inch):

  Total volume of all cylinders (numeric)

- Gross horsepower:

  Power of engine (numeric)

- Rear axle ratio:

  Number of revolutions the output shaft needs to make to spin the rear
  axle one complete turn (numeric)

- Weight(1000 lbs):

  Weight of car (numeric)

- Quarter mile time:

  Time taken to travel quarter of a mile (numeric)

- Engine:

  Type of engine (character)

- Transmission:

  Type of gearbox (character)

- Number of forward gears:

  Number of forward gears (numeric)

- Number of carburettors:

  Number of carburettors (numeric)

- Price(£):

  Price of car (character - numbers stored as text and \[c\] for missing
  values)

- Date1:

  Random date with no meaning (date)

- Date2:

  Random date with no meaning (date)
